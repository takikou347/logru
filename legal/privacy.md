# Logru プライバシーポリシー

kota（個人。以下「運営者」）は、Logru（以下「本サービス」）で扱う利用者の情報について、次のとおり定めます。

## 1. 運営者

- 名称: kota（個人）
- 住所と代表者: 個人で運営しているため、求めに応じて遅滞なくお答えします。下の窓口までご連絡ください。
- 連絡先: tkkwkut@gmail.com

## 2. 集める情報

| 情報 | 集める場面 |
| --- | --- |
| メールアドレス、表示名 | 登録するとき |
| パスワード | 登録するとき。元に戻せない形に変換して保存し、そのままでは持ちません |
| Google アカウントの名前、メールアドレス、アイコン画像 | Google でログインするとき |
| 予定の題名、日時、メモ | 予定を登録するとき |
| グループの名前、メンバー、招待の記録 | グループを作る、招待する、参加するとき |
| 表示の設定、色の設定 | 設定を変えるとき |
| 規約に同意した日時と版 | 登録するとき、規約を改めたとき |
| IP アドレス、ブラウザの種類、ログインした日時 | ログインしているあいだ |
| ログインに失敗した回数 | ログインに失敗したとき |

本サービスは、位置情報、写真、決済の情報を集めません。これらを扱う機能を追加するときは、このポリシーを改めます。

## 3. 使う目的

1. 本サービスを提供するため。ログイン、予定の表示、グループでの共有など
2. 登録の確認、パスワードの再設定などのメールを送るため
3. 不正なログインや利用を防ぐため
4. 不具合を直し、本サービスを改善するため
5. 規約の変更や本サービスの終了など、大切なお知らせを届けるため

## 4. 第三者への提供

運営者は、次の場合を除き、利用者の同意なく個人情報を第三者に提供しません。

1. 法令に基づく場合
2. 人の生命、身体または財産の保護のために必要で、本人の同意を得ることが難しい場合
3. その他、個人情報の保護に関する法律で認められている場合

なお、グループに共有した予定は、そのグループのメンバーが見ることができます。これは利用者自身の操作による共有です。

## 5. 取り扱いを任せる会社

本サービスは、次の会社のサービスを使って運営しています。いずれも米国の会社で、データは日本国外のサーバーで扱われることがあります。

| 会社 | 任せていること |
| --- | --- |
| Cloudflare, Inc. | 本サービスの配信とデータの保存 |
| Resend, Inc. | 確認メールと再設定メールの送信 |
| Google LLC | Google アカウントでのログイン |

米国には、日本と同じ水準の個人情報保護の法律が州によってはありません。運営者は、各社が個人情報の保護に関する方針を公開していることを確かめたうえで利用しています。

## 6. 外部への情報の送信

本サービスは、広告と利用状況の分析のためのツールを使っていません。

利用者が「Google でログイン」を押したときに限り、利用者のブラウザから Google LLC へ、ログインに必要な情報が送られます。送られた情報の扱いは、Google のプライバシーポリシーに従います。

## 7. 保存する期間

1. 利用者の情報は、アカウントがあるあいだ保存します。
2. アカウントを消すと、その利用者の情報を消します。バックアップからは、最長 30 日で消えます。
3. グループに共有した予定は、利用規約第3条第4項により、グループに残ります。そのとき、作った人の記録は消します。

## 8. 安全のための措置

1. パスワードは、元に戻せない形に変換して保存します。
2. 通信はすべて暗号化します。
3. ログインに続けて失敗したときは、一時的にログインを止めます。
4. データを扱えるのは運営者だけです。管理用のアカウントには二段階認証を設定します。

## 9. 開示、訂正、利用停止などの求め

利用者は、自分の個人情報について、開示、訂正、追加、削除、利用の停止、第三者への提供の停止を求めることができます。上の窓口までご連絡ください。本人であることを確かめたうえで、遅滞なく対応します。表示名と設定は、設定画面から自分で直せます。

個人情報の扱いについての苦情と相談は、上の窓口で受け付けます。
